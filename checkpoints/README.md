# Pretrained Checkpoints

Pretrained checkpoints are not included in this repository because of GitHub file size limits.

Download the official **SAM ViT-B** checkpoint from the Segment Anything repository:

https://github.com/facebookresearch/segment-anything

After downloading, place the checkpoint at:

```text
checkpoints/sam/sam_vit_b_01ec64.pth
```

or update the checkpoint path in the code if you use a different location.
